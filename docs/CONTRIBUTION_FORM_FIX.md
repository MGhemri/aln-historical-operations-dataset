# Correction des formulaires selon le type de contribution

- Nouvelle opération : aucun champ d’identifiant, attribution réservée au mainteneur ; date/période et lieux facultatifs sans précision inventée.
- Correction : sélection obligatoire d’une fiche existante et consignes spécifiques.
- Source : fiche existante et citation obligatoires ; justification d’absence masquée et exclue.
- Doublon : deux fiches existantes et différentes obligatoires ; aucune fusion.
- Contradiction : fiche existante et description des assertions et références divergentes.
- Toponyme : nom/variante obligatoires, fiche existante facultative.
- Champs masqués désactivés et exclus du récapitulatif. Les changements de type invalident le récapitulatif précédent.
- Sélecteurs alimentés par le corpus public ; titres arabes déjà présents réutilisés, IDs lisibles en LTR. Échec de chargement signalé, sans empêcher une nouvelle proposition sans ID.
- Modèles GitHub et guide alignés ; les champs d’ID libres des modèles GitHub nécessitent toujours une vérification humaine de leur existence.

Validation locale : 37 tests de données/API et 19 tests navigateur réussis ; exports vérifiés ; YAML des modèles valide ; captures FR/AR inspectées. Les 263 fiches sont inchangées.
